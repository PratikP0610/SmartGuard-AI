# SmartGuard-AI 🤖✨

## AI-Powered 3D Digital Twin & Predictive Maintenance System

**SmartGuard-AI** is an advanced industrial intelligence platform that combines **Machine Learning failure prediction** with an **interactive 3D WebGL Digital Twin** built in React 18, React Three Fiber, and Three.js. It analyzes real-time sensor parameters (Temperature, Vibration, Pressure, RPM, and Operating Hours) to detect mechanical anomalies before critical equipment failures occur.

---

## 🌟 Key Features

- **🌪️ Interactive 3D Industrial Turbine Digital Twin**:
  - Full 3D WebGL mesh with procedural titanium rotor blades, compressor stages, combustor core, and magnetic bearings.
  - **Dynamic Physics**: RPM-driven blade spin, vibration jitter oscillation, and particle vortex exhaust.
  - **Thermal FLIR Shaders**: Real-time metal heat coloration shifting from nominal cyan to warning crimson when temperature exceeds $90^\circ\text{C}$.
  - **Exploded CAD Mode**: Smoothly separates mechanical subsystems along the axis for internal component inspection.
  - **3D Hotspot Telemetry Pins**: Floating annotations anchored directly to physical sensor locations on the 3D model.

- **🧠 Zero-Latency Machine Learning Engine**:
  - Calibrated Random Forest Classifier (~100% test accuracy).
  - **Explainable AI (XAI)**: SHAP-inspired risk factor attribution and global Gini feature importance breakdown.
  - **Autopilot Telemetry Feed**: Continuous stochastic sensor drift simulation with live canvas oscilloscope waveforms.

- **💎 Cyber-Industrial Design System & ReactBits**:
  - Spotlight Cards with cursor-following specular lighting.
  - Magnetic CTA action buttons with spring damping.
  - Smooth animated number roll counters.
  - **ISO-13374 Diagnostic Certificate Generator**: Multi-format export (TXT, JSON, and printable reports).

## 🛠️ Technology Stack

### 3D Digital Twin Web Application
- **Frontend**: React 18, Vite 8, TailwindCSS (Cyber Theme)
- **3D & Graphics**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Animation & Motion**: Framer Motion, Canvas-Confetti
- **Icons**: Lucide React

### Machine Learning & Data Pipeline
- **Core ML**: Python 3, Scikit-Learn (Random Forest Ensemble, 100 Estimators)
- **Data Analysis**: Pandas, NumPy, Matplotlib, Seaborn
- **Legacy Prototype**: Streamlit

## 🚀 Getting Started

### 1. Run the 3D Digital Twin Web App (Recommended)

```bash
# Navigate to the frontend directory
cd frontend

# Install dependencies
npm install

# Start the Vite dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 2. Run the Python Streamlit Prototype

```bash
# Install Python requirements
pip install -r requirements.txt

# Launch Streamlit
streamlit run app.py
```
